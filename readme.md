The Use of Chaotic Mappings
Experiments have shown that the fitness function values generated by using chaotic mappings for random numbers generation significantly improve. Replacing conventional uniform distribution random number generators with chaotic mappings can yield better results, especially when there are many local solutions in the search space, making it easier to find the global optimal solution. In short, chaotic mappings enhance the randomness and diversity of particle states.

Results Analysis
Here, we selected optimization results for ten functions for display. The optimization results for these ten functions indicate that while chaotic mappings do enhance the performance of intelligent algorithms, they are not effective for every function. For example, F6 and F8.
It is important to note that theoretically, optimizing an intelligent algorithm with chaotic mappings merely makes the initialization of particles more random and diverse. This indeed can accelerate the convergence speed of the algorithm. However, once the loop begins, the remaining optimization process is largely unaffected by the chaotic optimization.
In other words, if I directly generate a bunch of particles using the rand function, there is a certain probability that they will be better than those generated by chaos optimization. Although this probability is not significant, it does exist. Therefore, if occasionally chaos optimization fails to perform well, do not be disheartened. After all, chaos optimization is just one means of optimizing intelligent algorithms; one can combine it with other methods for optimization.
